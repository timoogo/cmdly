---
title: "React Installation"
description: "Use Cmdly with React 18 or 19."
---

Install both packages: `pnpm add @cmdly/core @cmdly/react`. The React adapter re-exports the core types and functions, but importing headless APIs from `@cmdly/core` makes the boundary explicit.

`CommandPalette` renders semantic, unstyled HTML. Pass `commands` and it owns one engine per opening; pass an `engine` (plain or registry-backed) and it only displays that session.

The palette displays error messages verbatim: use messages safe for end users. It calls `onOpenChange(false)` after closing; the host must update `open`. Escape moves back from a step or menu and closes at the root or on a final screen (confirmation or result), and the host is responsible for page-level modal isolation.

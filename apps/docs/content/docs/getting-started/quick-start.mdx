---
title: "Quick Start"
description: "Open a command palette in a React app."
---

Install `@cmdly/core` and `@cmdly/react`, then render a `CommandPalette` with your commands. The palette creates its engine when it opens and destroys it when it closes; it brings keyboard navigation, search and focus handling, and no styles.

```tsx
import { useState } from 'react';
import { CommandPalette } from '@cmdly/react';
import type { Command } from '@cmdly/core';

const commands: Command[] = [{ id: 'hello', label: 'Say hello', run: () => alert('Hello!') }];

export function App() {
  const [open, setOpen] = useState(false);
  return <>
    <button onClick={() => setOpen(true)}>Open commands</button>
    <CommandPalette commands={commands} open={open} onOpenChange={setOpen} />
  </>;
}
```

To drive the same commands without React, see [your first command](/docs/getting-started/first-command). **Try it:** run `pnpm dev`, then choose **Simple command** in the playground's *Try it* grid.

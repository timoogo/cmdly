---
title: "Quick Start"
description: "Create a command and inspect the engine."
---

Create an engine with a command, select the command by its current displayed index, and destroy the engine when its owner is finished.
```ts
import { createCommandEngine, type Command } from '@cmdly/core';

const hello: Command = { id: 'hello', label: 'Say hello', run: () => console.log('Hello!') };
const engine = createCommandEngine({ commands: [hello] });
engine.select(0);
// When finished: engine.destroy();
```
For a visual interface, see the [React example](/docs/react/integration).

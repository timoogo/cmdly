description: "Public React exports."

`useCommandEngine(engine)` returns `{ state, actions }`; overloads preserve registry runtime typing. It subscribes to the supplied engine and does not create or destroy it.

`CommandPalette` takes either `commands` (it then creates and destroys one engine per opening) or an external `engine` it never closes or destroys (Escape and Cancel only call `onOpenChange(false)`; configure that engine yourself), plus `open`, `onOpenChange`, an optional `label` (dialog name, default `'Command palette'`), optional defaults, callbacks, strategies, plugins, `renderProgress`, `tokens` (global token types, applied live) and `tokenFeedback` (`'banner'` by default, `'loader'`, `'none'` or a component receiving `TokenFeedbackProps`). `CommandBubble` is a button that opens and closes a `CommandPalette` (`mode="trigger"`, default) or its own non-modal popover (`mode="standalone"`, closed by an outside press, focus leaving the bubble, Escape at the root or on a final screen, or completion): it takes the palette's props, `defaultOpen` or `open`/`onOpenChange`, a ref exposing `open()`, `close()` and `toggle()` (`CommandBubbleHandle`), `layout` (`'floating'` or `'inline'`), `placement` (`CommandBubblePlacement`, default `'bottom-right'`), `offset`, `trigger` (button content, or a function receiving `CommandBubbleTriggerProps` to render your own element) and `label`; it warns in development when several bubbles are mounted. `CommandPalette` and `CommandBubble` accept `children` as a function of the session's headless state (`CommandCombobox`) to replace the default view. `useCommandSession(options)` owns one session for a component's lifetime and `useCommandCombobox(engine, options?)` returns the headless state, actions and props of a session view (see React › Customization). `describeTokenIssue(token)` returns the default issue text. `CommandPaletteProps` is its public prop type. The adapter also re-exports the public core API.

## Signatures

```ts
useCommandEngine<TRuntime, TRuntimeRequired extends boolean>(
  engine: RegistryCommandEngine<TRuntime, TRuntimeRequired>,
): { state: EngineSnapshot<CommandView, RegistryRuntime<TRuntime>>; actions: RegistryCommandEngine<TRuntime, TRuntimeRequired> };
useCommandEngine(engine: CommandEngine): { state: EngineSnapshot; actions: CommandEngine };

type CommandPaletteProps = {
  open: boolean;
  onOpenChange: (open: boolean) => void;
  label?: string;
  tokenFeedback?: TokenFeedbackMode;
  renderProgress?: (progress: WorkflowProgress) => ReactNode;
  renderTag?: (tag: string, definition: ResolvedTagDefinition, command: CommandView) => ReactNode;
} & (
  | (Pick<EngineOptions, 'commands' | 'defaults' | 'callbacks' | 'strategies' | 'plugins'> & { tokens?: TokenOptions; engine?: never })
  | { engine: CommandEngine | RegistryCommandEngine; commands?: never; defaults?: never; callbacks?: never; strategies?: never; plugins?: never; tokens?: never }
);
function CommandPalette(props: CommandPaletteProps): React.JSX.Element | null;
// CommandPaletteProps and CommandBubbleProps also accept:
//   children?: (command: CommandCombobox) => ReactNode;
// CommandBubbleProps['trigger']: ReactNode | ((props: CommandBubbleTriggerProps) => ReactNode)

useCommandSession(options: Pick<EngineOptions, 'commands' | 'defaults' | 'callbacks' | 'strategies' | 'plugins' | 'tokens'>): CommandEngine;
// CommandSessionEngine: the engine operations an interface needs; any plain or registry engine satisfies it.
useCommandCombobox(engine: CommandSessionEngine, options?: { tokenFeedback?: TokenFeedbackMode; onDismiss?: () => void }): CommandCombobox;
// CommandCombobox is an explicit exported type: state, actions, back, dismiss, rootProps, inputProps, listboxProps,
// getOptionProps, listVisible, visibleItems, message, finalContext, tokens (see React › Customization).
```

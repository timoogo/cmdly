## Runtime exports

- `createCommandEngine({ commands, defaults?, callbacks?, strategies?, plugins? })` creates a legacy engine. `createCommandEngine({ registry, runtime?, ... })` creates a registry engine; the runtime provider is required when the registry requires it.
- `createCommandRegistry(...)` creates a composable registry. See [registries](/docs/registries/create-compose) for methods.
- `CommandUnavailableError` has a `qualifiedId`.

## Engine actions

`getSnapshot`, `subscribe`, `setCommands`, `setOptions`, `select`, `back`, `forward`, `setQuery`, `setActive`, `retry`, `execute`, `close`, and `destroy`. Registry engines add `refreshRegistry`; setting commands on a registry engine throws.

## Public types

`Answers`, `Option`, `Step`, `ProgressMode`, `WorkflowProgress`, `BackBehavior`, `FinalStatus`, `SummaryField`, `SummaryItem`, `FinalContext`, `FinalStep`, `CommandSettings`, `CommandContext`, `ContextualStep`, `ContextualFinalStep`, `ContextualCommand`, `Command`, `StepView`, `CommandView`, `EngineSnapshot`, `EngineCallbacks`, `EngineStrategies`, `EnginePlugin`, `EngineOptions`, `RegistryRuntime`, `RequiredRuntime`, `RegistryEngineOptions`, `CommandEngine`, `RegistryCommandEngine`, `ResolvedCommand`, and `CommandRegistry`.

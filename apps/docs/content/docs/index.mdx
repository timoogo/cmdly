---
title: "Introduction"
description: "A headless command and workflow engine for TypeScript and React."
---

Cmdly turns commands and multi-step workflows into a framework-independent store. Use it headlessly with `@cmdly/core`, or use `@cmdly/react` to subscribe from React or render the unstyled `CommandPalette`.

A command can run immediately, gather answers across steps, or contain nested commands. Registries let independent parts of an application contribute commands under namespaces.

Start with [installation](/docs/getting-started/installation), then build your [first command](/docs/getting-started/first-command).

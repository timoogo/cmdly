---
title: "Execution"
description: "Run commands and inspect results."
---

Selecting a leaf without a final step starts it. `execute()` runs a command in its final or running phase and prevents concurrent duplicate execution. Observe `status`, `result`, and `error` in the snapshot; do not rely on rejected promises to report a command failure. A successful command with no final step, or a before final step, closes by default and clears its status and result. Use an applicable final step with `closeOnComplete: false` to retain the result, or use an after final step whose condition passes. The `closeOnComplete` strategy can override the default.

Closing clears session answers. A closed engine is not reopened: create another instance for a new session. `destroy()` cancels pending results, removes listeners, and runs plugin cleanups.
